LENR-Sim methodology

Taxonomy, Learning vs Research Mode, and comparative workbench methodology.

LENR-Sim separates experiment/environment, known physical mechanisms, named LENR theories, proposed states/entities, and observed outputs. A universal cross-section multiplier is an educational abstraction only — not the Research Mode computational foundation.

Recommended workflow

  1. Choose experiment / environment
  2. Enter measured conditions
  3. Select candidate theories + Model 0 baselines
  4. Compare predicted signatures
  5. Inspect falsifiers, equation citations, and identifiability warnings

Learning Mode vs Research Mode

Learning Mode (SPA): conceptual explanations and simplified paths. Research Mode: author equations, model versions, units, uncertainties, and paper fidelity. Mode UI switch is deferred; metadata and static pages already expose Research Mode fields.

Honesty

No theory leaderboard credibility percentages. Maturity axes stay independent. EQ-OPEN-* remain open.
