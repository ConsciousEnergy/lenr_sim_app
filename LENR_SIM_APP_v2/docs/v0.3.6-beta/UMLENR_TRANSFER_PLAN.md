# UMLENR Transfer Plan (Selective)

## Policy
UMLENR assets are treated as upstream research inventory, not direct runtime merge candidates.

## Tiering
- **A-tier**: empirically traceable, maintained dependencies, testable integration path.
- **B-tier**: promising but needs refactor/calibration/tests before runtime.
- **C-tier**: archival/reference only.

## v0.3.6 Intake Checklist
- provenance source and date recorded
- empirical support class assigned
- compatibility with current API contract verified
- regression tests added for imported runtime components

## Runtime Constraint
Only A-tier artifacts may be integrated into runtime paths for v0.3.6.
